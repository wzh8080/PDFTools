- 对外部 I/O（文件读写、Intent 启动、ContentResolver 操作）统一用 `runCatching { ... }.onFailure { Log.e(TAG, ...) }` 包裹，失败路径降级为 toast 提示而非抛异常。
- 所有用户可见文件名经 `sanitize()` 过滤非法字符并强制 `.pdf` 后缀，长度截断至 120 字符。
- 需要更新 UI 的回调一律通过 `runOnUiThread { ... }` 执行，避免在异步回调中直接操作 View。
- 临时文件统一写入 `cacheDir` 下固定子目录（`pick`、`out`），并在写入新数据前清空旧内容。
