- 每个脚本采用相同的入口模式：通过 fileURLToPath(import.meta.url) 解析当前目录，从 process.argv[2]/[3] 获取输入输出路径，若缺失则回退到同目录 input.pdf 与默认输出名。
- 页面分栏数 n 根据源页宽高比 ratio = W/H 判定：ratio >= 1.85 取 3 栏，>= 1.2 取 2 栏，否则 1 栏。
- 目标页面统一使用 A4 尺寸 (595.276 × 841.89) 与 MARGIN=12 留白，缩放因子 s = min(availW/cw, availH/H)，居中坐标 x0=(A4W-dw)/2, y0=(A4H-dh)/2。
- PDF 加载统一传入 { ignoreEncryption: true } 以跳过加密检查，输出字节通过 fs.writeFileSync 写回磁盘并打印页数与 KB 大小。
