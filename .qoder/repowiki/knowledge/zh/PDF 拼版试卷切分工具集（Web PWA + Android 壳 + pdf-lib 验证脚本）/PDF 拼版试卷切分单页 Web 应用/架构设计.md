单页 PWA 应用，入口 `index.html` 通过 `<script>` 顺序加载 `lib/pdf.min.js`、`lib/pdf-lib.min.js` 后执行 `app.js`。
- 渲染层：pdf.js 负责解析与 Canvas 栅格化预览，并配置 `GlobalWorkerOptions.workerSrc` 指向 `lib/pdf.worker.min.js` 做离线程解析。
- 处理层：pdf-lib 负责页面嵌入 (`embedPages`) 与输出 A4 文档；所有二进制数据在 `ArrayBuffer` / `Uint8Array` 间传递，避免序列化开销。
- 状态层：IIFE 内 `state` 对象集中保存文件、尺寸、边距、模式等运行时状态，DOM 元素通过 `$(id)` 缓存引用。
- 关键算法：`normalizeRotation` 用 pdf-lib 的矩阵变换烘焙 `/Rotate`，解决 pdf.js viewport 与 pdf-lib 坐标系不一致问题；`trimBands` + `scanInk` 基于像素扫描检测每栏有墨迹矩形实现白边裁剪；`detectCols` 根据宽高比自动判定 1/2/3 栏。
- 扩展点：通过全局 `window.PdfShell` 桥接 Android 原生外壳进行大文件分块传输（Base64, 768KB 块），否则回退到 Blob 下载与 `navigator.share`。
- PWA：`manifest.json` 声明 `standalone` 显示模式与图标，配合 `icon.svg` / `icon-192.png` / `icon-512.png` 提供桌面与启动图标。
