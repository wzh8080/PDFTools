- 全局 DOM 访问统一通过 `$(id)` 包装函数获取元素，避免重复 `getElementById`。
- 异步流程采用 Promise 链式调用，并在耗时循环中插入 `await tick()`（`setTimeout(..., 0)`）让出事件循环以保持 UI 响应。
- 用户偏好（如白边裁剪开关）通过 `localStorage` 持久化，并以 try/catch 包裹以兼容 file:// 或隐私模式下的抛错。
- 二进制数据在 `ArrayBuffer`、`Uint8Array` 和 `Blob` 之间显式转换，pdf-lib 与 pdf.js 共用同一份字节缓冲以保证坐标一致。
- 可选的原生能力（`PdfShell`、`navigator.share`、`IntersectionObserver`）均通过特性检测分支处理，未启用时回退到标准 Web API。
