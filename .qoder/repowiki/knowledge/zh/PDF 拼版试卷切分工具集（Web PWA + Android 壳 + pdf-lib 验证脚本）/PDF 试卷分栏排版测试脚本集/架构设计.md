模块为扁平的 ESM 脚本集合（package.json 中 name 为 pdftool_test），无子目录与共享模块：
- debug.mjs：最小验证脚本，仅对第一页做左右两栏裁剪，用于确认 copyPages + setMediaBox 的行为。
- test.mjs：先 copyPages 再临时 addPage，随后通过索引倒序 removePage 清理中间页，实现单页内多栏布局。
- test2.mjs：使用 embedPage(sp, bb) 直接按 bbox 嵌入每栏，逐页处理。
- test3.mjs：先收集全部 sp/bb 后一次调用 embedPages 批量嵌入，利用 copier 跨栏复用资源，并在 save 时启用 useObjectStreams。
所有脚本均独立运行，依赖方向单一：Node fs/path/url → pdf-lib.PDFDocument；pdfjs-dist 虽声明在 package.json 但未被任何脚本引用。输入默认取同目录 input.pdf（已在 .gitignore 忽略真实试卷），输出路径由第三个参数或默认文件名控制。
